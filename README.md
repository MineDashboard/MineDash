## Инструкция для README.md проекта MineDash

### MineDash

MineDash - это инструмент для мониторинга и управления вашими майнинг-фермами. Он предоставляет удобный интерфейс для отслеживания производительности и состояния оборудования.

**Клонируйте репозиторий:**
   ```bash
   git clone --recurse-submodules https://github.com/MineDashboard/MineDash.git
   cd MineDash
   ```
